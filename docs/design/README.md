# Design mockups

One HTML file per feature. Written by `/design`, reviewed in the browser before any code is written.

## Naming

`[feature-name].html` — matches the feature name used in `features/[name]/`.

## Usage

Open in any browser. Includes a dark mode toggle and tab navigation between screens.
Review and give feedback before approving. Approval is the gate to Phase 4 (tech design).

## Contents

- `overview.html` — full product overview (from `/kickoff`)
- `[feature-name].html` — per-feature mockups (from `/feature` Phase 3)
